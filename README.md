## 報價計算邏輯

### 六層計費架構

```
外幣原始成本
  → × (1 - 廠商折扣%)         # 折在成本上
  → × 匯率 × (1 + 匯差%)      # 台幣換算
  → × (1 + 顧問獎金%)         # 佣金計入
  → - 公司折扣                # 二次折扣
  → × (1 + 營業稅%)           # 含稅售價
```

**淨利 = 稅前收入 - 折後成本 + EP 回傭**

## 系統功能

### 報價 Wizard（7 步驟）

1. 選擇學校（EP）
2. 選擇校區與課程
3. 設定週數與學生資訊
4. 選擇住宿
5. 加購選項（簽證、考試費等）
6. 折扣設定（廠商折扣 + 公司折扣）
7. 確認與匯出

### 即時費用預覽

- 右側面板即時更新
- 顯示各費用明細（外幣 + 台幣換算）
- 管理員可見計費層與淨利試算

### 報價單匯出

- **學生版** — 只顯示費用明細與台幣總額，不含計費層
- **內部版** — 顯示完整六層計費、回傭與淨利試算
- 格式：PNG 圖片（html2canvas）

### 歷史報價紀錄

- 命名規則：`學生-學校-日期-v版本數`
- 支援複製、載入舊報價
- Firebase Firestore 雲端同步，多裝置共用

## 管理員設定（費率管理）

可於後台調整：

- 匯率（AUD / GBP / EUR / USD / CAD）
- 匯差緩衝 %（預設 2%）
- 顧問獎金 %（預設 2%）
- 營業稅 %（預設 5%）
- EP 回傭率（預設 5%）
- 報價有效天數（預設 30 天）
- 匯率提醒天數（預設 7 天）
- 廠商折扣方案（期間限定，按校區設定）
- 公司折扣方案（原價 / 優惠價 / 出清價 / 固定折抵）
