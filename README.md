## 報價計算邏輯

### 六層計費架構

```
外幣原始成本
  → × (1 - 廠商折扣%)         # 折在成本上
  → × 匯率 × (1 + 匯差%)      # 台幣換算
  → × (1 + 顧問獎金%)         # 佣金計入
  → - 公司折扣                # 二次折扣
  → × (1 + 營業稅%)           # 含稅售價
```

**淨利 = 稅前收入 - 折後成本 + EP 回傭**

### 匯率參數（含 2% 匯差）

| 幣別 | 匯率 |
|------|------|
| GBP | 41.82 |
| EUR | 35.19 |
| AUD | 21.93 |
| USD | 32.64 |
| CAD | 23.97 |

### 取整規則

- ≤ 500 → 歸零
- 501–999 → 取 500
- ≥ 1000 → 正常進位

## 系統功能

### 報價 Wizard（7 步驟）

1. 選擇學校（EP）
2. 選擇校區與課程
3. 設定週數
4. 選擇住宿
5. 加購選項
6. 折扣設定
7. 確認與匯出

### 即時費用預覽

- 右側面板即時更新
- 顯示各費用明細
- 管理員可見計費層與淨利試算

### 報價單匯出

- **學生版** — 只顯示「海外學雜費 NT$XX」，不列明細
- **內部版** — 顯示完整六層計費明細
- 格式：PNG 圖片

### 歷史報價紀錄

- 命名規則：`學生-學校-日期-v版本數`
- 支援複製、載入舊報價
- Firebase 雲端同步，多裝置共用
